# M3 — Responsibilities

Each building block has a distinct responsibility. "Must not" lists what belongs elsewhere to keep component boundaries clear (see [M12 — Risks and technical debt](../M12-risks-technical-debt/README.md) for where current code violates these boundaries by reading XML inside calculation strategies).

| Block | Responsible for | Must not | Owns data | C4 Level 4 (Depth Level 2) Reference |
|---|---|---|---|---|
| `PropulsionDesign` (coordinator) | 5-phase lifecycle (`initialize`, `run`, `update`, `report`, `save`); building `geometry::Aircraft`; creating, sorting, and validating propulsors (`check_validity()`); instantiating one strategy per discipline (`select_*`); dispatching strategies in sequence via `std::visit` for every propulsor | Contain discipline-specific engineering calculation formulas | `this->engines` (`std::vector<PropulsionType>`), `aircraft_geometry`, `reference_offset`, selected strategy pointers, `report::Data` | [`PropulsionDesign_MainCPP.drawio`](../M7-runtime/PropulsionDesign_MainCPP.drawio), [`PropulsionDesign_Initialize.drawio`](../M7-runtime/PropulsionDesign_Initialize.drawio), [`PropulsionDesign_Run.drawio`](../M7-runtime/PropulsionDesign_Run.drawio) |
| `design::EngineDesigner` / `Rubber` | Reading `engine_mass` and `engine_efficiency` tech factors; preselecting or auto-selecting the reference engine from `path_engine_database` with minimum SLST deviation; scaling deck CSV values (`scale_deck_data_values`) and exporting scaled CSV decks (`write_deck_value`); computing `N1` with penalties, scale factor, Raymer scaled dimensions/mass, and `BucketPoint` | Position the engine on the airframe; build nacelle or pylon 3D surface sections | `preselected_engines_`, `designed_engines_` set, `engine_database_`, `engine_directory_`, `flight_condition_`, `technology_factors` | [`PropulsionDesign_Run.drawio`](../M7-runtime/PropulsionDesign_Run.drawio) (`engine_designer->operator()`) |
| `geometry::NacelleDesigner` / `nacelle::Default` | Reading nacelle profile `.dat` names per propulsion ID; constructing 3D multi-section polygon surfaces for the nacelle and engine core using `aircraftGeometry2` (`SectionBuilder`) based on fan/engine dimensions | Decide the global engine position on the aircraft | `section_shapes` map, nacelle and core `geom2::MultisectionSurface` sections | [`PropulsionDesign_Run.drawio`](../M7-runtime/PropulsionDesign_Run.drawio) (`this->nacelle_designer`) |
| `design::PropulsionIntegrator` / `integration::Default` | Positioning each propulsion system on its parent component (`Wing`, `WingBody`, `Fuselage`, `Empennage`) using geometric rules and `usershift_x/y/z` offsets; checking span/empennage collision bounds; falling back to `CGAL::ORIGIN` (`guess_position()`) if aircraft geometry is absent | Size the engine or modify nacelle/pylon cross-section contours | `n_engines_`, `engines_done` (`EngineCount`), `parents_placed`, global engine position | [`PropulsionDesign_Run.drawio`](../M7-runtime/PropulsionDesign_Run.drawio) (`this->propulsion_integrator`) |
| `geometry::PylonDesigner` / `pylon::Default` | Reading pylon airfoil `.dat` profiles per propulsion ID; computing attachment points between the nacelle and parent surface (`Wing`, `WingBody`, `Fuselage`); building the 3D pylon `MultisectionSurface` | Modify the nacelle surface or engine scale factor | `section_profiles` map, pylon `geom2::MultisectionSurface` sections | [`PropulsionDesign_Run.drawio`](../M7-runtime/PropulsionDesign_Run.drawio) (`this->pylon_designer`) |
| `mass::MassAnalyzer` / `mass::Default` | Computing point masses, CG vectors (`Eigen::Vector3d`), and inertia tensors (`Eigen::Matrix3d`) for Engine, Nacelle, and Pylon components using `geom2::measure::centroid()` / `inertia()` and applying mass technology factors | Change component geometry or placement | `technology_factors` (`engine_mass`, `nacelle_mass`, `pylon_mass`), `PointMass` map per component | [`PropulsionDesign_Run.drawio`](../M7-runtime/PropulsionDesign_Run.drawio) (`this->mass_analyzer`) |
| `geometry::Aircraft` | Parsing wing, fuselage, and empennage geometry nodes from `acXML` via `geom2` factories (`WingFactory`, `FuselageFactory`, `AirfoilFactory`) and transforming origins to global coordinates | Modify propulsion objects | `wings`, `fuselages`, `empennages` (`geom2::MultisectionSurface` vectors) | [`PropulsionDesign_Initialize.drawio`](../M7-runtime/PropulsionDesign_Initialize.drawio) (`create_geometry()`) |
| `io::AircraftXML` & `io` engine XML | Reading inputs from and inserting sized propulsion results (`reference_offset`, total propulsion mass, per-engine geometry/mass/bucket point) into `acXML` (`AircraftXMLv3`); loading unscaled (`io::load_engine_data`) and scaled (`io::load_engine_scaled`) engine XML datasets | Contain sizing or geometric calculation logic | Versioned `AircraftXMLInterface` pointer | [`PropulsionDesign_Initialize.drawio`](../M7-runtime/PropulsionDesign_Initialize.drawio) (`io::load_engine_data`), [`PropulsionDesign_Run.drawio`](../M7-runtime/PropulsionDesign_Run.drawio) (`io::load_engine_scaled()`) |
| `report` | Aggregating takeoff/SLST data and generating N1 `BucketCurve` with and without offtakes (`report::generate_data()` in `update()`); exporting `create_html_report()`, `create_xml_report()`, and `Matplot++` / SVG plots (`create_plots()`) in `report()` | Mutate sized propulsion design parameters | `report::Data`, `report::BucketCurve` | [`PropulsionDesign_Update.drawio`](../M7-runtime/PropulsionDesign_Update.drawio), [`PropulsionDesign_Report.drawio`](../M7-runtime/PropulsionDesign_Report.drawio) |
| Engine library (`UnicadoLibs::engine`, external) | Parsing CSV engine decks (`DeckData::from_csv`), linear deck interpolation, shaft/bleed off-take penalty iteration (`calculate_N1_with_penalties`), and unscaled SLST lookup | — | `EngineData`, `Engine`, `DeckData` | [`PropulsionDesign_Initialize.drawio`](../M7-runtime/PropulsionDesign_Initialize.drawio) (`DeckData::from_csv`), [`PropulsionDesign_Run.drawio`](../M7-runtime/PropulsionDesign_Run.drawio) (`engine_unscaled.calculate_N1_with_penalties()`) |

## RACI for change requests

| Change | Responsible block | Also affected |
|---|---|---|
| New engine sizing method | `design` (new `EngineDesigner` subclass + `select_engine_designer()` in `propulsion_design.cpp`) | Configuration ([M9](../M9-configuration/README.md)), Technical debt ([M12](../M12-risks-technical-debt/README.md)) |
| New powertrain or energy carrier | Data model (`propulsion.h`, `energy_carrier.h`, `utility::create_engine`) plus **every** discipline strategy | All 5 discipline strategies; `io::AircraftXML`; [M9](../M9-configuration/README.md); [M12](../M12-risks-technical-debt/README.md) |
| New engine parent position | `integration::Default` (`default_integration.cpp`) & `pylon::Default` (`get_attachment_points()`) | [M4](../M4-interfaces/README.md) interface table, [M9](../M9-configuration/README.md) position combinations |
| New `acXML` schema version | `io::detail::AircraftXMLInterface` implementation (e.g., alongside `AircraftXMLv3`) | All consumers of the `acXML` |
| New report or plot content | `report` (`report_data.cpp`, `create_html_report.cpp`, `create_xml_report.cpp`, `create_plots.cpp`) | [M4](../M4-interfaces/README.md) I4 outputs |
